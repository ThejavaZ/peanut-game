# Screenshots — how to name them

Drop the captures of the beta in **this folder** using exactly these names, and
the `README` section will render them with no further editing.

| File | Scene to capture | Caption shown in the README |
| ---- | ---------------- | --------------------------- |
| `01-menu.png` | Main menu with a run in progress | Menu with an active run and the cemetery entrance |
| `02-adoption.png` | Naming screen with the skin shelf | Name field and the 21 skins |
| `03-play.png` | Live room: five bars, clock, **score badge** | Five bars, clock, score and the minigame panel |
| `04-event.png` | Event modal open | A choice with its consequences, clock stopped |
| `05-warning.png` | Critical alert banner | The warning that arrives before health falls |
| `06-wheel.png` | Hamster Wheel mid-session | `Swings 2/3` — attempts and capped reward |
| `07-maze.png` | Tiny Maze with the exit visible | Real walls and the green exit |
| `08-gap.png` | Minigame panel during the 60 s gap | Buttons disabled with the countdown |
| `09-memorial.png` | Memorial after a death | Final score, cause of death and epitaph |
| `10-cemetery.png` | Cemetery with at least two graves | Every past run with cause, date and score |
| `11-tests.png` | Terminal with `bun test` and the CI run green | 148 tests and a green pipeline |

**Tips**

- Crop to the browser window: no desktop, no other tabs.
- PNG is fine; keep each one under ~500 KB so the README stays light.
- A capture of the **wheel** or the **maze** is worth more than a third menu shot.
- The game is live at <https://thejavaz.github.io/peanut-game/>.

Once the eleven files are here, the `## Screenshots` section of the root
`README.md` renders automatically — nothing else has to be edited.
